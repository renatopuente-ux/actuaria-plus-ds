1 · Átomos

Los bloques indivisibles. Un átomo no se puede dividir sin perder su función y no contiene otros componentes del sistema. Si necesitas combinar dos, eso ya es una molécula.

La ley de relieve

Vale para todo el sistema y no admite excepciones. Es lo que permite al actuario saber qué puede tocar sin probar nada.

RELIEVE
HUNDIDO
Solo informaPLANO

Por qué funciona

  • Es binaria: no hay estado intermedio que interpretar
  • Sobrevive al daltonismo: la señal es la sombra, no el color
  • Un componente nuevo se clasifica solo respondiendo «¿se pulsa?»

Cómo se rompe

  • Dar relieve a las tarjetas: si todo sobresale, nada sobresale
  • Hundir los chips para que «no parezcan botones»: sigue siendo neumorfismo
  • Quitar el relieve a un botón por estética

Botón

.a-btn

La acción. Siempre en píldora y siempre en relieve: es la señal de que se puede pulsar. El acento naranja se reserva para UNA acción por pantalla.

principal · acción de sistema
por defecto
acento · una por pantalla
fantasma · descartar
deshabilitado · se aplana
sm · 34px
lg · 52px

Usar cuando

  • La acción es real y el usuario puede ejecutarla ahora
  • Necesitas jerarquía: principal > por defecto > fantasma
  • El botón deshabilitado explica por qué lo está (tooltip o texto)

Nunca

  • Dos botones de acento compitiendo en la misma vista
  • Usar el naranja de marca puro como fondo con texto blanco: da 3.7:1
  • Radio pequeño: deja de distinguirse de una tarjeta
  • Quitar el relieve para que «se vea más limpio»: pierde la señal de pulsable
<button class="a-btn a-btn--principal">Calcular provisión</button>

Botón de icono

.a-icono

Acción sin texto. Círculo perfecto. Obligatorio aria-label: sin él, un lector de pantalla anuncia un botón vacío.

descargar
filtrar
sm · 34px

Usar cuando

  • El icono es inequívoco (cerrar, descargar, más)
  • El espacio es escaso: barras de herramientas, filas de tabla

Nunca

  • Iconos ambiguos sin etiqueta visible al lado
  • Omitir aria-label
  • Usarlo para la acción principal de una pantalla
<button class="a-icono" aria-label="Descargar informe">⇩</button>

Campo de texto

.a-campo

Entrada de datos. Hundido: en neumorfismo un campo es un pozo donde se deposita el dato. Esa metáfora separa de un vistazo lo que se escribe de lo que se pulsa.

normal
error · anillo rojo

Usar cuando

  • Cualquier dato que el usuario escriba o pegue
  • Marcar los obligatorios con data-obligatorio en la etiqueta
  • Usar aria-invalid y un mensaje que diga cómo arreglarlo

Nunca

  • Ponerle relieve: parecería un botón
  • Usar solo el color rojo para indicar error
  • Placeholder como sustituto de la etiqueta: desaparece al escribir
<label class="a-etiqueta" for="c1" data-obligatorio>Razón social</label>
<input class="a-campo" id="c1" placeholder="YUPANA ANALYTICS S.A.">

Chip de estado

.a-chip

Informa, no actúa. Plano y opaco. Opaco importa: un relleno con alpha hereda la superficie de debajo, y el mismo chip medido daba 8:1 sobre claro y 1.3:1 sobre navy.

Pendienteaviso · 6.58:1

Usar cuando

  • Estado de una fila, una valuación o un pedido
  • Metadato corto: plan, normativa, periodo

Nunca

  • Darle relieve: fingiría que se puede pulsar
  • Rellenos con rgba: el contraste cambia según el fondo
  • Usar los niveles 500 del brandbook como color de texto: no llegan a 4.5:1

Barra y esqueleto

.a-barra · a-esqueleto

Espera. La barra sirve cuando se conoce el porcentaje; el esqueleto, cuando no. Ambos van hundidos: son superficie, no acción.

barra · 62%
esqueleto · carga desconocida

Usar cuando

  • Barra: subida de nómina, cálculo con progreso real
  • Esqueleto: primera carga de una tabla o un panel

Nunca

  • Barra con porcentaje inventado para «tranquilizar»
  • Esqueleto con forma distinta del contenido que va a llegar
  • Animar sin respetar prefers-reduced-motion

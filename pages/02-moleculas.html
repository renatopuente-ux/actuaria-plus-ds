2 · Moléculas

Grupos de átomos que juntos hacen un trabajo. Una molécula compone: no introduce color ni sombra propios. Si necesita un valor que no existe como átomo, falta un átomo.

Grupo de campo

.m-campo

La unidad real de un formulario: etiqueta, campo, ayuda y error. La etiqueta va encima y el error debajo y en línea, nunca solo como borde rojo.

Anual efectiva, en porcentaje
Debe estar entre 60 y 70 años

Usar cuando

  • Cualquier entrada de un formulario real
  • El campo necesita explicación: unidad, formato o rango
  • Hay que mostrar un error de validación

Nunca

  • Señalar el error solo con el borde rojo: el color por sí solo no es accesible
  • Usar el placeholder como etiqueta: desaparece al escribir
  • Vaciar el campo cuando la validación falla
<div class="m-campo m-campo--obligatorio">
  <label class="a-etiqueta" for="tasa">Tasa de descuento</label>
  <input class="a-campo" id="tasa" aria-describedby="tasa-ayuda">
  <span class="ayuda" id="tasa-ayuda">Anual efectiva, en porcentaje</span>
</div>

Buscador

.m-busqueda

Campo hundido con la lupa dentro. El botón de limpiar aparece solo cuando hay texto.

Usar cuando

  • La lista supera las 12 filas
  • El usuario sabe qué busca y puede nombrarlo
  • Se acompaña de un estado vacío cuando no hay resultados

Nunca

  • Obligar a pulsar Intro: filtra mientras se escribe
  • Dejar el botón de limpiar visible con el campo vacío
  • Devolver «0 resultados» sin sugerir qué hacer
<div class="m-busqueda">
  <svg>...</svg>
  <input class="a-campo" type="search" aria-label="Buscar">
  <button class="limpiar" aria-label="Limpiar búsqueda">...</button>
</div>

Usar cuando

  • El dato resume el estado de un estudio o una cartera
  • La variación tiene un periodo de referencia explícito
  • Hay sitio para el rótulo completo sin recortarlo

Nunca

  • Variación solo en color: añade siempre flecha y signo
  • Cifras sin tabular-nums: la columna salta al actualizarse
  • Más de cuatro indicadores en una fila

Pasos del asistente

.m-pasos

Actuaria+ usa la variante navegable: su asistente permite volver a un paso anterior pulsándolo, así que los completados son botones con relieve. La variante plana queda para flujos que no dejan saltar — darle relieve a un paso que no responde hace que el usuario lo pulse y crea que está roto.

  1. Datos del colectivo

  3. 3 Tablas biométricas
  4. 4 Resultados
Variante plana, para flujos que no dejan saltar

Usar cuando

  • El flujo tiene principio y fin conocidos, como el alta de un estudio
  • Informativo si el asistente valida cada paso y no deja saltar
  • Navegable solo si volver a un paso anterior funciona de verdad
  • El paso completado lleva marca, no solo un color distinto

Nunca

  • Dar relieve a un paso que no se puede pulsar: el usuario lo intentará y creerá que está roto
  • Hacer botón el paso actual: ya estás en él
  • Hacer botón un paso futuro: aún no tiene sus datos
  • Más de siete pasos visibles a la vez

Barra de filtros

.m-filtros

Un filtro se pulsa, así que lleva relieve y es un <button> con aria-pressed. No confundir con la etiqueta de estado, que es plana porque solo informa.

4 de 1 842 filtradas

Usar cuando

  • Hay más de 20 filas y categorías conocidas
  • El filtro activo se puede quitar con un segundo clic
  • Se muestra cuántos resultados quedan

Nunca

  • Usar .a-chip como filtro: es plano porque no se pulsa
  • Filtros que requieren pulsar «Aplicar» para surtir efecto
  • Ocultar que hay filtros activos al cambiar de pestaña
<button class="filtro" aria-pressed="true">Vigentes</button>
<button class="filtro" aria-pressed="false">Vencidas</button>

Paginación

.m-paginacion

Dentro de un <nav> con nombre. La página actual se marca con aria-current="page", y el rango dice siempre de cuántos.

61–90 de 1 842

Usar cuando

  • La lista supera unas 50 filas
  • El usuario necesita saber cuántos elementos hay en total
  • La posición se conserva al volver desde el detalle

Nunca

  • Ocultar el total: el usuario no sabe cuánto queda
  • Paginar por debajo de 25 filas: mejor mostrarlas todas
  • Marcar la página actual solo con un color distinto
<nav class="m-paginacion" aria-label="Paginación de pólizas">
  <span class="rango">61–90 de 1 842</span>
  <button class="pag" aria-current="page">3</button>
</nav>

Mensaje de sistema

.m-alerta

Rellenos opacos, siempre con icono además del color. Solo el de error usa role="alert"; los demás usan role="status" para no interrumpir al lector de pantalla.

Usar cuando

  • Informar del resultado de una acción del sistema
  • El mensaje dice qué pasó y qué hacer a continuación
  • El error conserva lo que el usuario había escrito

Nunca

  • Mostrar códigos de error crudos o trazas
  • Culpar al usuario o escribir «Inválido» a secas
  • Dar un fallo de guardado solo en un aviso que se cierra solo
  • Usar role="alert" en mensajes que no son urgentes

Estado vacío

.m-vacio

Una pantalla vacía es una invitación a actuar, no un cartel de «no hay datos». Siempre lleva la acción que la llena.

Sin estudios todavía

Un estudio reúne el colectivo, las hipótesis y las tablas biométricas para calcular la provisión.

Usar cuando

  • Una lista está vacía por primera vez
  • Una búsqueda o un filtro no devuelve resultados
  • Se puede explicar en una frase para qué sirve lo que falta

Nunca

  • Dejar solo «No hay datos» sin salida
  • Mostrarlo mientras aún se está cargando: ahí va un esqueleto
  • Poner la ilustración y esconder la acción
<div class="m-vacio">
  <h3>Sin estudios todavía</h3>
  <p>Un estudio reúne el colectivo, las hipótesis y las tablas.</p>

    <button class="a-btn a-btn--principal">Crear el primer estudio</button>
  </span>
</div>
